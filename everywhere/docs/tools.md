# Tools for FreeSTAR Everywhere

We have listed below some tools you can use which will assist with setting up devices and services to use with FreeSTAR Everywhere

## Tools for [RF Links](./guides/rf-links/index.md)

- [IAX2 String Generator](https://freestareverywhere.com/apps/iax2string-generator/) - _create an IAX2 string to give to support when requesting an RF Link_
- [IAX2 Config Generator](https://freestareverywhere.com/apps/iax2config-generator/) - _create IAX2 config files for your Allstar node_
